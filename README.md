# AI Advent Challenge #9 — Week 06, Day 27

**Trigger Helper** — продуктовый SPA самопомощи по триггерным точкам (Svelte 5 + Fastify). День 27 добавляет **историю диалога в локальной ветке**: мульти-ход без облака — локальная модель (Ollama) получает предыдущие ходы через клиентский `contextTail` и отвечает с опорой на диалог. Попутно починена облачная ветка (rail-повтор с fail-open + `tool_choice:"required"` — пустые ответы ProxyAPI больше не роняют ход) и настройки модели собраны в один пункт «Модель» (облачные + локальные одним списком). Живое демо: https://trigger.ksvitkov.ru

## Demo на видео (~1:39)

1. **Настройки → «Модель»** — единый пункт: групповой список («Облачные» / «Локальные (Ollama)» с бейджами доступности), статус рантайма и каталог; выбор Qwen2.5 1.5B.
2. **Чат A — два связанных хода локальной 1.5B**: ход 1 — суммаризация карточки подостной с живым прогрессом «● N ток»; ход 2 («почему?») опирается на ход 1 — история реально уехала в Ollama (в трейсе «Генерация (локальная)», чип «локальная · без RAG», сессия ₽0.00).
3. **Чат B — те же вопросы на облачной (дефолт free deepseek)**: развёрнутые ответы с чипом «Источники 12 · цитаты 2/5», рельса каждого хода ✓ (rag-вызов + метки источников), ₽0.00/ход.
4. **Сравнение переключением чатов** — в кадре обе ленты с одними вопросами: короткие локальные против объёмных облачных с источниками.
5. **Тот же код на проде** — гейтинг по RAM слабого хоста: 0.5B «доступна», 1.5B/3B «мало RAM».

## Выводы

ответы облачной модели более объемные. для локальной модели промпт и жесткие ограничения должны быть заданы очень внимательно, тогда можно получить приемлемо лаконичные ответы

## Что где реализовано

| Пункт задания | Где |
|:---|:---|
| История диалога в локальной ветке | `server/src/services/local-llm.ts` — `LocalLlmChatParams.history` + `localHistoryTurns` (капы под `num_ctx 2048`: последние 6 сообщений, ≤400 симв./сообщение, ≤1500 суммарно, старейшие отрезаются первыми); `server/src/routes/chat.ts` — локальная ветка принимает клиентский `contextTail`, `trace.historyMessages` показывает фактическую историю |
| Мульти-ход без облака (ядро дня) | ход 2 «почему?» отвечает по тексту хода 1; проверка — `npm run local-llm:check -- --history` (2 хода; PASS = непустые ответы и рост prompt_tokens) |
| Облачная ветка (восстановлена cust-fix'ом) | `server/src/services/agent/llm-agent.ts` + `deepseek.ts`: rail-повтор обёрнут в fail-open + повтор с `tool_choice:"required"` — пустые ответы ProxyAPI не роняют ход; матрица 3 модели × 2 хода 6/6 |
| Настройки модели — один пункт | `client/src/lib/components/SettingsScreen.svelte`: пункт «Модель» с групповым дропдауном (облачные + локальные с бейджами), статус рантайма и каталог Ollama; выбор — одна ручка `overrides.model` |

## Быстрый старт

```bash
npm install                # воркспейсы: shared + server + client
npm run build              # shared → server → client (SPA собирается последней)

# локальная ветка: Ollama + модель каталога (0.5b — слабые хосты, 1.5b — по RAM)
ollama pull qwen2.5:0.5b

cd server
npm run dev                # API на :3000 (DEEPSEEK_API_KEY / ProxyAPI в server/.env — для облачной ветки)
npm run local-llm:check -- --history   # мульти-ход локальной ветки: 2 хода + токены/латентность

# SPA — второй терминал из корня репо
npm run dev:spa            # vite :5173, /api проксируется
```

## Demo через API

```bash
# каталог моделей с бейджами доступности (облачные + локальная секция)
curl http://127.0.0.1:3000/api/models

# ход 1 локальной моделью
curl -N -X POST http://127.0.0.1:3000/api/chat -H "Content-Type: application/json" \
  -d '{"input":"Сожми в одно предложение: …","preset":"rag_chat","contextTail":{},"overrides":{"model":"qwen2.5:0.5b"}}'

# ход 2 с ИСТОРИЕЙ диалога: предыдущая пара уходит в contextTail.dialogue
# (сервер кладёт её в промпт локальной модели; trace.historyMessages = 2)
curl -N -X POST http://127.0.0.1:3000/api/chat -H "Content-Type: application/json" \
  -d '{"input":"Почему? Опираясь на предыдущий ход.","preset":"rag_chat",
       "contextTail":{"dialogue":[{"role":"user","content":"ход 1…"},{"role":"assistant","content":"ответ 1…"}]},
       "overrides":{"model":"qwen2.5:0.5b"}}'
# → {"type":"done","result":{reply, trace, usage}}
```

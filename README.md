# AI Advent Challenge #9 — Week 05, Day 24

**Trigger Helper** — RAG-ответы с обязательными источниками и цитатами + режим «не знаю» при слабом контексте (анти-галлюцинации тремя слоями). Продуктовый стек: TypeScript · Fastify · DeepSeek · UI одним файлом. Живое демо: http://91.188.212.10 (блок «RAG» в правом доке).

## Demo на видео (~1:05)

Всё — в UI (без терминала):

1. **Контрольный вопрос (base)** — карточка: ответ-рассказ + источники (`source › section` + `chunk_id`) + блок **«Цитаты»**: дословные фрагменты из найденных чанков, счётчик «цитат: 5 · верифицировано: 5» — каждая цитата проверена сервером на дословность.
2. **Кнопка «10 контрольных вопросов · eval»** — карточка-матрица: 10 вопросов × 4 режима с колонками **ист/цит/досл/смысл** — все три проверки задания видны без терминала; отдельная секция **off-corpus** (5/5).
3. **Off-corpus вопрос** («как настроить VPN») — карточка **«не знаю · слабый контекст»**: просьба уточнить + метрика «косинус top-1 = 0.769 &lt; порог 0.838» — порог релевантности прослеживается в UI.

## Выводы

для вывода этого дня пришлось анализировать не столько внешнее поведение модели, а внутренние аспекты. Зная, что модель может рассказывать "разное" очень убедительно, жесткие проверки и простейшая жесткая (пороговая) категоризация позволяют ввести новое измерение - достоверность результата. И с учетом вероятностной природы ответов модели гарантировать проверяемость основных цепочек (используемые цитаты), что повышает достоверность общего ответа (логичные связки ПРАВИЛЬНЫХ данных/исходных терминов и т.п.). Свободы для "галлюцинаций" у модели намного меньше, чем при базовом "промптовом" способе взаимодействия.

## Что где реализовано

| Пункт задания | Где |
|:---|:---|
| Ответ обязательно со списком источников (source + section/chunk_id) | `server/src/services/rag/answer.ts` — payload `sources[]` (серверная правда) + `quotes[]` с адресацией по `chunk_id` |
| Цитаты (фрагменты из найденных чанков) | jsonMode-структура `{answer, quotes[{quote, chunk_id}]}` + серверная верификация `validateQuotes`: цитата обязана быть нормализованной подстрокой инжектированного чанка; невалидные сбрасываются, 0 валидных → серверные fallback-фрагменты (инвариант «цитаты ≥ 1») с честным флагом `quotes_source` |
| Проверка на 10 вопросах: источники/цитаты/смысл | `server/src/scripts/eval-rag-answer.ts` + артефакт `data/rag/eval-answers.json`: ист **40/40**, цит **40/40**, дословность **39/40** (независимая перепроверка), смысл-прокси + ручной проход **10/10**; в UI — eval-карточка с колонками |
| Усиление: ниже порога → «не знаю» + уточнение | dontKnow-гейт до ответ-вызова: косинус top-1 против порога из `data/rag/tune-dontknow.json` (тюнинг: 12 on-corpus + 5 off-corpus проб; зазора нет → консервативный порог 0.8375); срабатывание — канонический текст, ₽0, ~25 мс |
| Результат | Ответы с обязательными источниками и цитатами (валидация на сервере, а не «надежда на промпт») + режим «не знаю»; матрица: base 0.83/7 PASS — регресса от формата нет, честная цена цитат ~+1.4k ток |

## Быстрый старт

```bash
cd server && npm install && npm run dev
# ключ: DEEPSEEK_API_KEY в server/.env

# порог «не знаю» + реранк-порог (локально, ₽0; сервер остановить: ledger — единый писатель)
npm run rag:tune      # → data/rag/tune-dontknow.json + tune-rerank.json

# проверка на 10 контрольных + off-corpus (сервер остановить)
npm run rag:eval      # → data/rag/eval-answers.json
```

## Demo через API

```bash
# обычный вопрос — ответ + источники + верифицированные цитаты
curl -X POST http://127.0.0.1:3000/api/rag/ask \
  -H "Content-Type: application/json" \
  -d '{"q":"Аритмия без боли от точки между рёбрами — правда? Где искать точку?","mode":"rag"}'
# → { answer, sources[{source,section,chunk_id,score}], quotes[{quote,chunk_id,source,section}],
#     meta{quotes_source:"model", quotesValid:5, ...} }

# слабый контекст — «не знаю» + просьба уточнить (без LLM-вызова, ₽0)
curl -X POST http://127.0.0.1:3000/api/rag/ask \
  -H "Content-Type: application/json" \
  -d '{"q":"как настроить VPN на компьютере","mode":"rag"}'
# → { answer:"Не знаю — в базе знаний нет ничего релевантного. Уточните вопрос (мышца, симптом, техника)?",
#     sources:[], quotes:[], meta{dontKnow:true, topCosine:0.769, threshold:0.838} }

# артефакты: порог — data/rag/tune-dontknow.json, матрица — /api/rag/eval
curl http://127.0.0.1:3000/api/rag/eval
```

Деградация (дизайн-контракт): битый/отсутствующий tune-артефакт → гейт «не знаю» выключается с warn (ask не падает); сбой jsonMode → плоский вызов дня 22 + серверные цитаты (`meta.degraded:"format"`); реранкер на хосте без весов → 503 только rerank/full arms; сбой LLM → 502; дневной бюджет → 429.

# AI Advent Challenge #9 — Week 07, Day 33

**Trigger Helper** — продуктовый SPA самопомощи по триггерным точкам (Svelte 5 + Fastify). День 33 — **ассистент поддержки пользователей**: кнопка «+ Поддержка» открывает чат с ИИ-специалистом — приём жалобы живым текстом, одно уточнение за ход, контекст по email из тикет-стора, короткие ответы из FAQ и честная эскалация человеку без обещаний сроков.

## Demo на видео

Два класса вопросов (два чата):

1. **ИИ закрывает сам** (лимит бесплатных вопросов): приём → «лимит 20 из 20, а я спрашивала два раза» → email → `crm_get_user` → «это дневной лимит free-тарифа, не сбой; после полуночи ходы вернутся» → вежливый финал. Решено без человека.
2. **Эскалация повторным обращением** (502): приём → «Ошибка 502» → совет подождать → «ждала 10 минут — всё равно не работает» → email → обращение #19 «в работе у инженеров», без сроков.

В трейсе каждого хода — поиск по FAQ (`support_search`) и тулзы тикет-стора (`crm_get_user`); у ответов — чип «Источники». Первый ответ за сутки открывается приветствием по местному времени клиента.

## Выводы

Бот в качестве первой линии поддержки уровня "прочти наконец инструкцию" выглядит очень полезным, но надо обратить отдельное внимание на стилистику разговора, так как всякие эмпатии в этом (техническом_) контексте крайне бесят обычно.

## Что где реализовано

| Пункт задания | Где |
|:---|:---|
| Мини-сервис поддержки в Agent UI | кнопка «+ Поддержка» → тред пресета `support` (kill-switch `SUPPORT_ENABLED`) |
| Отвечает на вопросы о продукте | FAQ-корпус `data/support-rag/` (4 источника / 24 чунка), тулза `support_search` |
| Контекст пользователя/тикета | read-only тикет-стор `data/support/{users,tickets}.json` + `crm_get_user` / `crm_get_ticket` / `crm_list_tickets` (fail-closed) |
| Через MCP: CRM или JSON с тикетами | те же `crm_*` как in-process tools в tool-loop llm-agent |
| Пример «почему не работает?» | два класса: ограничение — ИИ закрывает сам; сбой — честная эскалация, без сроков |
| Ассистент поддержки (результат) | воркфлоу живого специалиста: приветствие первым ответом за сутки (по местному времени клиента) → приём → одно уточнение за ход → контекст по email → решение/эскалация; эмпатия дозирована |

## Быстрый старт

```bash
npm install
npm run build
npm run rag:index:support -w server   # индекс FAQ поддержки (один раз)

cd server && npm run dev              # http://localhost:3000 — кнопка «+ Поддержка»
```

# AI Advent Challenge #9 — Week 06, Day 26

**Trigger Helper** — продуктовый SPA самопомощи по триггерным точкам (Svelte 5 + Fastify). День 26 добавляет **локальную LLM**: Ollama на устройстве пользователя подключается к общему каталогу моделей чата — с гейтингом доступности по RAM, живым прогрессом генерации в трейсе и нулевой ценой локальных ходов. Облачная ветка (DeepSeek) остаётся дефолтом. Живое демо: https://trigger.ksvitkov.ru

## Demo на видео (~0:57)

1. **Настройки → «Локальная модель»** — рантайм Ollama «доступен», каталог с бейджами: Qwen2.5 0.5B / 1.5B «доступна», 3B «не установлена» — недоступные видны, но не выбираются.
2. **Три хода в чате на локальной Qwen2.5 1.5B** — вопросы по карточкам базы триггерных точек: факт (растяжка до деактивации точек → «Нет»), суммаризация карточки подостной одним предложением, рассуждение по фактам базы (подостная vs дельтовидная → «Подостная»). В трейсе каждого хода — живой прогресс «● N ток · T с»; чип модели — «локальная · без RAG»; цена хода ₽0.00.
3. **HTTP API в кадре** — сырой JSON `GET /api/models` с local-секцией каталога (чат-ходы идут через `POST /api/chat`, SSE).
4. **Тот же код на проде** — гейтинг по RAM слабого хоста: 0.5B «доступна», 1.5B/3B «мало RAM».

## Выводы

локальные сети доступны для простой суммаризации и понимания текста, их можно использовать успешно для поиска и/или реформулирования вопросов.
В то же время локальная сеть (на слабом хосте) не знает многих вещей, просто основные понятия и связи языка (уже много). При суммаризации требует аккуратного промптинга, т.к. может терять важные по смыслу (но не токенам) понятия - вроде "не нужно" = "нужно".
В остальном, с учетом "бесплатности" и полной конфиденциальности данных - важная альтернатива облачным.

## Что где реализовано

| Пункт задания | Где |
|:---|:---|
| Установить и запустить локальную LLM | Ollama 0.40 (локально + VPS), модели `qwen2.5:0.5b` / `qwen2.5:1.5b`; сервис `server/src/services/local-llm.ts` — каталог, probe (`GET /api/tags`, кэш + single-flight), NDJSON-стрим с буфером хвоста строки |
| Доступ через HTTP API | `GET /api/models` — local-секция каталога с бейджами; чат-ходы локальной моделью — `POST /api/chat` (SSE) |
| Ответ на простой запрос | ход 1 в демо: «Нет.» по тексту карточки базы (1.1 с · 133 ток · ₽0.00) |
| ≥3 запроса разной сложности | три хода демо — факт / суммаризация / рассуждение по карточкам `data/points/`; CLI-проверка — `npm run local-llm:check` (3 запроса + таблица токены/латентность) |
| Прогресс во время подсчёта | SSE-шаг `local-gen`: «Генерация (локальная) · ● N ток · T с» в трейсе хода |
| Выбор модели, недоступные не выбираются | секция «Локальная модель» в настройках SPA: бейджи «доступна / мало RAM / не установлена», гейтинг по `os.totalmem`; выбор модели — `overrides.model` в `POST /api/chat` (fail-closed allow-list) |

## Быстрый старт

```bash
npm install                # воркспейсы: shared + server + client
npm run build              # shared → server → client (SPA собирается последней)

# локальная ветка: Ollama + модель каталога (0.5b — слабые хосты, 1.5b — по RAM)
ollama pull qwen2.5:0.5b

cd server
npm run dev                # API на :3000 (DEEPSEEK_API_KEY в server/.env — для облачной ветки)
npm run local-llm:check    # CLI-проверка локальной ветки: 3 запроса разной сложности + токены/латентность

# SPA — второй терминал из корня репо
npm run dev:spa            # vite :5173, /api проксируется
```

## Demo через API

```bash
# каталог моделей с бейджами доступности (локальные + облачные)
curl http://127.0.0.1:3000/api/models

# ход в чате локальной моделью (SSE: step local-gen → done; локальная ветка отвечает одной ходкой без RAG)
curl -N -X POST http://127.0.0.1:3000/api/chat -H "Content-Type: application/json" \
  -d '{"input":"Сожми в одно предложение: …","preset":"rag_chat","contextTail":{},"overrides":{"model":"qwen2.5:0.5b"}}'
# → {"type":"step","step":"local-gen","text":"…"} … {"type":"done","result":{reply, trace, usage}}
```

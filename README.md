# AI Advent Challenge #9 — Week 07, Day 35

**Trigger Helper** — продуктовый SPA самопомощи по триггерным точкам (Svelte 5 + Fastify). День 35 — **реальная задача: сервис с AI в реальном окружении**. Человек с сидячей мышечной болью (шея/плечи/руки/голова) за минуты находит у себя вероятную мышцу-источник и получает технику самопомощи с проверяемыми цитатами из классической литературы; бот помощи отвечает на вопросы по самому продукту.

## Demo на видео

Живой сервис (HTTPS), два пользователя в разных браузерных профилях — у каждого свои треды:

1. **П1 (новый):** «Появилась тянущая боль сбоку шеи, отдаёт в висок. Что это может быть и что с этим делать?» → мышца-кандидат (верх трапеции), шаги самопомощи, чип «Источники 8» с карточками цитат `[source › section]`.
2. **П1:** «Что можно сделать прямо сейчас, пока я на работе?» → приёмы на рабочем месте за минуту-две.
3. **П2 (другой профиль, бот помощи):** «Как выбрать модель для ответов?» → по FAQ: чип модели, бесплатные — всем, дорогие — Pro. «А моя история где-то сохраняется?» → только в браузере, регистрации нет.
4. **П1 возвращается в свой тред** (заголовок треда = сама жалоба, история на месте): «А если боль усиливается при повороте головы в сторону?» → продолжение разбора без повторного объяснения — контекст помнится.
5. **Негативный сценарий (финал):** «А если тянет под правым ребром?» → честный отказ: в базе такой зоны нет, без выдуманных мышц и источников.

## Выводы

в результате работ по адвент челленджу получился рабочий прототип, позволяющий получить адекватные и точные (проверяемые цитатами) инструкции по самопомощи на основании классической литературы в этой области. Самому прочитать, выучить и применять подобные знания непросто. Но применять сами методы - доступно каждому. Методы работы с ИИ (изученные на челлендже) позволяют выстроить адекватный диалог с пользователем и, повторюсь, убедиться в корректности выдаваемой информации.

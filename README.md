# AI Advent Challenge #9 — Week 05, Day 22

**Задание:** реализовать функцию: вопрос → поиск релевантных чанков → объединение с вопросом → запрос к LLM. Сравнить ответ модели без RAG и с RAG. Усиление: мини-набор из 10 контрольных вопросов по вашей базе — для каждого ожидание и источники (если применимо). Результат: агент с двумя режимами (с RAG / без RAG) + 10 контрольных вопросов и сравнение качества. Формат: видео + код.

Trigger Helper (day22): RAG работает **на базе знаний продукта** — 43 md-карточки триггерных точек (Травелл т.1 + практика Дэвиса, пересказ без цитат, атрибуция источников). **Два режима одного эндпоинта** `POST /api/rag/ask` {q, mode}: **с RAG** — эмбеддинг-поиск (structured, k=12) → контекст ≤3k токенов → deepseek-chat, ответ с цитатами `[source › section]`; **без RAG** — тот же вопрос той же модели, которая сама ищет по карточкам «обычным» способом: обзор базы (`list_points`) → чтение карточек (`get_point`), без эмбеддингов. Сравнение честное: одна модель, temperature 0, одинаковый лимит ответа. В UI — pair-карточка «без RAG / с RAG» в чате: обе панели с ответами, источниками и **ценой доступа** (токены · время · число вызовов) в каждой.

**Eval — 10 контрольных вопросов:** для каждого зафиксированы ожидание (must-mention факты) и ожидаемые источники; скоринг детерминированный (вопросы → поиск → ответ, без LLM-судьи), плюс обязательные **токены и время**. Итог прогона: **качество ответов с RAG выше — 0.83 (PASS 7/10) против 0.75 (5/10) без RAG** — и это при **~2.7× меньшем бюджете токенов** (~3 763 против ~10 070) и чуть меньшем времени (~3.8 с против ~4.2 с: baseline тратит раунды на чтение карточек целиком). Ретрив попадает в ожидаемый источник в 90% вопросов.

## Что где реализовано

| Требование | Где |
|:-----------|:----|
| База знаний (карточки точек) | `data/points/*.md` — 43 карточки; `tools/content-pipeline/render_cards.py` рендерит их из пайплайна |
| Вопрос → поиск чанков → склейка → LLM | `services/rag/answer.ts` (`RagAnswerService.ask`) — поиск top-k → контекст ≤3k токенов (сброс целыми чанками) → deepseek-chat (temp 0, 900 tok, 60 с) |
| Два режима (с RAG / без RAG) | `mode: "rag"` — контекст из поиска; `mode: "baseline"` — та же модель без контекста (честное сравнение) |
| API | `routes/rag.ts` — `POST /api/rag/ask` (400 zod / 429 бюджет / 502 LLM / 503 индекс; rate-limit + budget-throttle + ledger), `GET /api/rag/eval` — артефакт сравнения |
| 10 контрольных вопросов | `data/rag/eval-questions.json` (вопрос, ожидание — must-mention факты, источники) + `scripts/eval-rag-answer.ts` (`npm run rag:eval`) — таблица 10×2, токены/время, `data/rag/eval-answers.json` |
| UI | `server/public/index.html` — RAG-блок (select режима, кнопки «Спросить» и «10 контрольных вопросов · eval»), pair-карточки в чате с ответами, источниками, токенами и временем |
| Ledger | `services/usage-ledger.ts` — все вызовы ask/eval пишут usage (deepseek-chat, не expensive) |

## Быстрый старт

```bash
git clone https://github.com/kosvitko/trigger-helper-advent.git
cd trigger-helper-advent
git checkout week05-day22
cp .env.example .env        # нужен только DEEPSEEK_API_KEY (эмбеддинги локальные)
npm install
npm run rag:index           # корпус карточек → чанки → эмбеддинги → data/rag/
npm run dev                 # http://127.0.0.1:3000 — блок «RAG» в правой панели

# сравнение на 10 контрольных вопросах (токены/время в таблице)
npm run rag:eval
```

## Demo через API

```bash
# ответ с RAG (контекст из карточек + цитаты)
curl -X POST http://127.0.0.1:3000/api/rag/ask \
  -H "Content-Type: application/json" \
  -d '{"q":"аритмия без боли от точки между рёбрами — какая мышца и где точку искать?","mode":"rag"}'

# тот же вопрос без RAG (честный базлайн)
curl -X POST http://127.0.0.1:3000/api/rag/ask \
  -H "Content-Type: application/json" \
  -d '{"q":"аритмия без боли от точки между рёбрами — какая мышца и где точку искать?","mode":"baseline"}'

# артефакт сравнения на 10 контрольных вопросах
curl http://127.0.0.1:3000/api/rag/eval
```

Деградация (дизайн-контракт): индекс отсутствует/повреждён → `503 {error}` и сервер живёт; сбой LLM → `502`; исчерпан дневной бюджет → `429`.
